# 音画同步阅读器 (audio-text-sync)

一个纯前端、轻量、移动端友好的网页应用：上传一个文档（`.pdf` / `.txt` / `.md`）和一个音频文件（`.mp3` / `.wav` / `.m4a` 等），让你"边听边看"。

设计目标是**学习场景**——不是逐字对齐字幕器，而是帮你保持视线和听觉同步的阅读伴侣。

## 特性

- **纯浏览器，无后端、无模型**：主包仅约 200 KB，iPhone Safari 也能流畅运行。
- **段落级切分**：文本按段落（不是逐句）切分，PDF 会自动按字号/Y 间距推断段落边界。
- **PDF 噪声过滤**：自动忽略**水印**（旋转文字）、**页眉页脚**（多页重复内容）、**页码**（数字 / `第 X 页` / `Page X`）。
- **按字数均匀分布**：上传后立即按段落字符数估算每段在音频中的位置。
- **单击 = 跳转音频**：点段落 → 音频 seek 到该段开头。
- **双击 = 对齐当前播放点**：听到偏差时双击当前段，"剩余段落"会按字数比例重新分布到音频剩余时长。多次双击逐步收敛。
- **段落自动滚动**：阅读区独立滚动，不会带飞整个页面。

## 技术栈

- Vite + React + TypeScript
- `pdfjs-dist`（懒加载，只在打开 PDF 时下载）

## 开发

```bash
npm install
npm run dev
```
