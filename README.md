# 音画同步阅读器 (audio-text-sync)

一个纯前端的网页应用：上传一个文档（`.txt` / `.md`）和一个音频文件（`.mp3` / `.wav` / `.m4a` 等），自动把音频中朗读的内容与文档段落对齐，让你"边听边看"，并自动高亮当前正在朗读的段落。

## 特性

- **无需后端**：所有处理（音频解析、语音识别、模糊匹配）都在浏览器里完成。
- **模糊对齐**：即便音频内容只是文档的一部分，或两者文字略有出入（口误、改写、漏读、跳读），仍可通过 Levenshtein 距离 + 滑动窗口匹配。
- **两种模式**：
  - **自动模式**：使用 [`@xenova/transformers`](https://github.com/xenova/transformers.js) 在浏览器中跑 Whisper 模型，得到带时间戳的转写结果，再与原文档对齐。首次会下载模型（约 80~200 MB，浏览器会缓存）。
  - **手动模式**：你提供文档 + 音频，直接按段落均匀分布时间戳；用于网络受限或想要快速预览的场景。
- **可点击跳转**：点击任意段落即可让音频跳到对应时间。
- **可调速**：0.5x ~ 2x 播放，并支持快进/快退 5 秒。

## 技术栈

- Vite + React + TypeScript
- `fastest-levenshtein` 做字符级编辑距离
- `@xenova/transformers` 跑浏览器内 Whisper（可选）

## 开发

```bash
npm install
npm run dev
```
